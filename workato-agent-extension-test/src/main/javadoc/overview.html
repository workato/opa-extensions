Test-time harness and fakes for Workato on-premise agent extensions.

Two complementary tools: AgentExtensionHarness (in-memory MockMvc harness, no agent installed) and DeployedAgentLauncher (in-process real-agent launcher against a deployed distribution). The fake webhook implementation (FakeAgentWebhookApiV1) scripts responses and captures the call log so unit tests can assert against outbound deliveries without opening a socket.

The customer-facing usage guide — quick start, YAML fixtures, stub/assert patterns, DeployedAgentLauncher setup — lives alongside this javadoc as README.md. Open it from the same directory (your IDE's "Javadoc" tab unpacks the jar, so the link resolves to the file next to index.html).
